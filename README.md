# Transaction Monitoring & Fraud Detection Dashboard

## 📌 Description
This project focuses on analyzing transaction data to identify unusual patterns and potential fraud activities. The dashboard helps in monitoring transactions and improving decision-making.

## 🎯 Objective
- Identify suspicious transactions
- Perform data validation and cleansing
- Track key performance metrics
- Support fraud detection process

## ⚙️ Tools Used
- Excel
- SQL
- Power BI

## 📊 Key Features
- Transaction trend analysis
- Detection of anomalies in data
- KPI tracking (accuracy, flagged transactions)
- Interactive dashboard for insights

## 🔍 Use Case
This project simulates real-world banking operations where analysts review transactions to detect fraud and ensure compliance.

## 🚀 Outcome
Improved data accuracy and helped in identifying potential risk patterns in transactions.
