# Retail Sales Analysis Project

This is an end-to-end Data Analytics project using Python, SQL, and Power BI to analyze retail sales and generate insights.

## Project Includes:
- Python Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Business Insights
- Power BI Dashboard
- Synthetic Retail Dataset

## Files Included:
- Cleaned CSV files
- SQLite database (retail_analytics.db)
- Python scripts (data_cleaning.py, eda.py)
- SQL query files
- EDA Notebook
- Sample charts (monthly sales, top products)

## Key Steps:
1. Clean data using Python
2. Analyze using SQL queries
3. Visualize using Power BI
4. Generate business insights

## Tools Used:
- Python (Pandas, NumPy, Matplotlib)
- SQL (SQLite)
- Power BI
- Jupyter Notebook
